After that, day to day

    

      
On every PR
The Ownership check status, the developer's summary, and the concepts they explained per file.

      
Emergencies
Add the skip-ownership-check label. CI skips the check, and the label stays in the timeline.

      
Plugin updated?
Upgrade the repo's copy in its own PR: node <plugin>/dist/gate.mjs install --upgrade --repo .

      
Nobody can switch it off in a PR
CI runs the gate and the config from the base branch, not from the PR.
